# MASTER SOUND EFFECTS (SFX) LIBRARY — CANONICAL CHANNEL TEMPLATE

Este diretório armazena a biblioteca permanente de efeitos sonoros (SFX) para produções do canal.

Consulte a especificação canônica completa em:
`channels/dossie-historico/recursos_globais/sfx/README.md`

### Categorias Padronizadas:
- `01_transicoes/`: Whooshes curtos e lentos para cortes e transições de cena.
- `02_impactos/`: Booms graves, sub-drops e braams orquestrais para revelações e clímax.
- `03_documentos_foley/`: Viradas de página, pergaminhos, manuseio de pastas e carimbos.
- `04_epoca_tecnologia/`: Obturadores de câmeras antigas e tique-taques mecânicos.
- `05_tensao_risers/`: Crescendos de tensão e elementos de época (lâminas, metais).

### Regras de Áudio:
- WAV 48kHz estéreo.
- Normalização de pico em -6dBFS.

# OmniPress Tech & Software Engineering Skill

Use this skill when drafting articles, LinkedIn posts, X threads, or Reddit submissions focused on software engineering, dev tooling, code architectures, or tech tutorials.

## Tone & Writing Guidelines
- **Audience**: Software engineers, tech leads, engineering managers, devops specialists.
- **Voice**: Pragmatic, evidence-based, curious, no marketing fluff.
- **Focus Areas**:
  - Architectural trade-offs (why we chose X over Y).
  - Code snippets and system diagrams.
  - Performance benchmarks and post-mortems.

## Target Platform Tuning
1. **Long-Form (Dev.to / Substack / Blog)**:
   - Deep tutorial or architecture post with formatted code blocks.
   - Frontmatter tags: `programming`, `architecture`, `opensource`, `webdev`.
2. **LinkedIn**:
   - Focus on leadership, system design lessons, and engineering culture.
   - 3-5 bulleted technical takeaways.
3. **X (Twitter) & Threads**:
   - Code snippet screenshots, benchmark highlights, and fast tips.
4. **Reddit**:
   - Target `r/programming`, `r/webdev`, `r/SideProject`, or language-specific subs (`r/rust`, `r/python`, `r/vuejs`).
   - Title must highlight problem/solution: *"How we eliminated 90% of memory spikes in our queue worker"*.
